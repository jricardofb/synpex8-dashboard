# v0.6.3 — Consolidacao final

## Principais alteracoes

1. **Ativo universal**
   - Master pode enviar `GOLD`, `USTEC`, `XAUUSD.a`, etc.
   - `MasterAssetMapping` resolve para `UniversalAsset`.
   - `BrokerAssetMapping` resolve para o simbolo real do cliente.

2. **Exposicao por contrato**
   - O lote do Master nao e copiado cegamente.
   - `contractSize` do Master e do broker sao considerados.
   - `EXACT` rejeita conversoes que nao representem a exposicao alvo.
   - `FLEXIBLE` permite adaptacao dentro do limite do Robot.

3. **Margem**
   - `marginAllocation` continua sendo referencia/planejamento.
   - `maxMarginMultiplier` e opcional e desativado quando 0.
   - A regra real continua `marginRequired <= freeMargin` depois das reservas concorrentes.

4. **Seguranca por Master**
   - Nao existe mais segredo global para sinais.
   - Cada Master tem segredo proprio, cifrado com `MASTER_SECRET_ENCRYPTION_KEY`.
   - HMAC usa os bytes exatos recebidos.
   - `x-master-id` identifica o Master e precisa coincidir com o corpo.
   - nonce permanece no Redis por pelo menos 2x a janela.

5. **Execucao**
   - Apenas uma conta ativa por cliente no fan-out v1.
   - Partial fill continua distinto de PARTIAL_CLOSE.
   - CLOSE/PARTIAL_CLOSE/MODIFY seguem a reconciliacao existente.

6. **Rebate**
   - Nao foi implementado. A decisao e deixar o rebate fora do Copy Engine.
